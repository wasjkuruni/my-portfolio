# Wk Raaj Portfolio

A responsive personal portfolio made with HTML, CSS, and JavaScript.

## Files
- `index.html` — website content
- `style.css` — colors, layout, and responsive styling
- `script.js` — mobile menu and small interactions

## Publish on GitHub Pages
1. Open your repository: https://github.com/wasjkuruni/my-portfolio
2. Upload these three files to the **repository root** (the first page, alongside `README.md`).
3. If GitHub asks, choose to replace the existing `index.html`, `style.css`, and `script.js`.
4. Click **Commit changes**.
5. Wait 1–3 minutes, then refresh https://wasjkuruni.github.io/my-portfolio/

The mountain background and portrait use external Unsplash image URLs, so an internet connection is needed for those images.

## Customize
- Change the displayed name/email in `index.html`.
- Update the colors near the top of `style.css` inside `:root`.
- Replace the social links and sample project cards with your real profiles and projects.
